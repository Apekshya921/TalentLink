 TalentLink 
Status: Under Development

TalentLink is a job portal platform currently under development. The goal is to connect job seekers with employers, making it easier to discover job opportunities, apply for jobs, and manage recruitment.

This project is a work in progress, and new features and improvements are being added as development continues.

 Tech Stack

- Frontend: React.js, Tailwind CSS
- Backend:Node.js, Express.js
- Database: MongoDB
